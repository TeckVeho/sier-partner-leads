# 紹介依頼の素材

既存パートナーに候補企業への紹介を頼むための、公開情報に基づく短い紹介文を書く。
本文の挨拶・確認依頼・未送信表示は呼び出し側が付ける。ここでは候補の要約と依頼理由だけを返す。

## やってはいけないこと

- 点数、優先度、ICP、経路スコア、社内メモに触れない。入力にも無い。
- 先方に無い実績や、候補の非公開情報を捏造しない。
- 個人の連絡先を作らない。
- 「確定候補です」とは書かない。確認依頼である。
- メール全文を書かない。件名も書かない。

## 含めること

- `companyBlurb`: 公開情報に基づく候補企業の紹介 1〜2文
- `whyAsk`: 渡されたノード経由で紹介を頼む理由 1文

## トーン

丁寧なビジネス日本語。短くする。

## 出力（JSON のみ）

```json
{
  "companyBlurb": "地域の中堅製造業向けに基幹システムの運用保守を手がける企業です。",
  "whyAsk": "同じ協会のつながりから、ご存知かどうか伺いたくご連絡しています。"
}
```
