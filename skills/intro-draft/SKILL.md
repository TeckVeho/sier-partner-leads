# 紹介依頼の下書き

既存パートナーに、候補企業への紹介を頼むメール本文を書く。
ARO がこのスキルを読み、`intro_requests.draft_body` に保存する。自動送信はしない。

## やってはいけないこと

- 送信した体の文面にしない。
- 先方に無い実績や、候補の非公開情報を捏造しない。
- 個人の連絡先を作らない。
- 件名だけの出力にしない。本文を書く。
- 「確定候補です」とは書かない。確認依頼である。

## 含めること

- 宛先は経由パートナー名
- 候補の社名と所在地
- なぜそのノード経由なのか（共通の協会・販売店網など）
- 優先度は参考情報として一言
- 末尾に、下書きであり送信前確認が必要である旨

## トーン

丁寧なビジネス日本語。3〜8段落。長くしない。

```json
  "source": "llm"
}
```
